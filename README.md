# Pokediction Arcade demo

A static, mobile-friendly prototype for the Pokediction concept.

## Current scope
- Local browser storage for play coins, streak, score, and recent activity
- Simulated Pokémon-inspired prediction arena
- No accounts, no multiplayer, no live market feed, no real-money transactions, and no payment integration

## Deploy
This repository includes a GitHub Actions workflow at `.github/workflows/deploy.yml`. In the repository settings, enable **Pages** and select **GitHub Actions** as the build/deployment source. The workflow runs after pushes to `main` or via manual dispatch.

If GitHub Pages is unavailable for this private repository on the current plan, change the repository visibility to public (after reviewing its contents) or connect a supported static host.

**Important:** This is a demo only. Do not represent it as a live exchange or enable real-money prediction without appropriate backend security, legal review, compliance, and tested payment infrastructure.
